## 수집 방법

1. `curl`로 `https://business.daangn.com/success-story?type=marketer` / `?type=smb` HTML 저장
2. Next.js `self.__next_f.push([1,...])` 스트림 청크를 Python 정규식으로 파싱해 각 사례의 `title`과 `thumbnail.asset._ref` 매칭
3. `cdn.sanity.io/images/r9at8elq/production/{ref}-{WxH}.{ext}` URL로 조합해 다운로드
4. 홈 히어로 이미지(비즈프로필)는 `business.karroter.net/daangn-business/home-v2/` CloudFront에서 직접 획득
5. 2MB 초과 파일은 Sanity `?w=1280&q=75` 변환 매개변수로 축소 후 재저장

## 참고: 커버되지 않은 항목

- **브랜드프로필 대형 히어로 UI 스크린샷**: `home-v2/brand_profile.png`이 180x180 아이콘이라 제외. 사례 썸네일(맘스터치·오늘의집)로 대체함.
- **7 카테고리 모두 사례 썸네일 이미지** 위주라 실제 앱 내 UI 스크린샷(피드 배너, 인앱 리드폼 시트 등)은 부족함. Naver blog / Tistory 후기 페이지를 추가 크롤링해야 실 UI 캡처를 얻을 수 있음.
