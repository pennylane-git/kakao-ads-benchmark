요약

  • 배민 광고 상품(핵심) 총 10개 — (셀프서브형 4) 우리가게클릭·오픈리스트·울트라콜/파워콜(구)·우리가게플러스, (프리미엄/브랜드형 3) 배민 상단 배너·배민1 상단 배너·프로모션 스토어, (커머스형 2) B마트/배민스토어 검색·카테고리 광고, (부가형 1) 배민장부/배민페이 결제 완료 후 배너. 셀프서브 축이 규모의 대부분을 차지하고 대형 브랜드는 프리미엄/시즌 프로모션 위주 [출처: ceo.baemin.com (사장님광장) 배민광고 페이지; woowahan.com 뉴스룸; 관찰·추정].
  • 카톡 아젠다 매핑 상위 3개
    1. 주문 완료 후/결제 완료 후 배너 ↔ 아젠다 4(선물하기·톡딜 서비스 종료 광고) — 카톡 톡딜/선물하기 결제 완료 화면 광고 신설의 가장 강력한 벤치마크. 배민은 "성공 트랜잭션 직후"의 광고 지면을 이미 운영해 광고주 만족도가 높은 것으로 알려져 있음(제휴 광고 형태) [관찰·추정, 카톡 벤치마크 목적으로 도입 필요성 강조].
    2. 셀프서브 우리가게 시스템 전체 ↔ 아젠다 6(오픈채팅 플로팅/띠배너)·아젠다 7(더보기 탭 신규 포맷) — 30만+ 소상공인 셀프 개설·자동 매칭·경매 입찰 시스템. 카톡 오픈채팅 방장/카톡채널 사업자에게 그대로 이식 가능한 세계 최상급 로컬 셀프서브 벤치마크 [출처: 우아한형제들 뉴스룸; 사장님광장 광고안내].
    3. 배민 홈 상단 배너(비즈보드 슬롯 유사) ↔ 아젠다 1(비즈보드 보장형 고도화)·아젠다 2(커스텀 비즈보드) — 홈 최상단 슬롯을 배민이 시즌·CPT 보장형으로 판매하며 대형 F&B/이커머스가 상시 집행. 카톡 비즈보드 확장 시 "동적 사이즈/포지션 + 시즌 CPT" 조합 참고.
  • 신규 시드 상위 3개
    1. 입찰형 로컬 검색광고(오픈리스트/우리가게클릭) — 카톡 오픈채팅·비즈 채널 검색 상단에 CPC/CPA 입찰형 로컬 광고 지면 신설(카톡채널 검색·오픈채팅 방 검색 상단). 카톡 아젠다 밖 신규 시드.
    2. 선주문/픽업 프로모션 스토어 지면 — B마트/배민스토어 커머스에서 브랜드가 "가상 스토어"를 개설하고 소비자가 앱 내에서 이벤트·샘플·리워드를 받는 형태. 카톡 톡딜 종료 후 대체 상품으로 매력적.
    3. 주문 완료 화면 브랜드 스폰서 — 결제 완료 순간 "이 주문은 ○○브랜드가 응원해요" 형태의 스폰서십 스티커. 카톡 선물하기 결제 완료 화면에 그대로 이식 가능.
  • 주요 성과 벤치마크 및 매출 지표: 우아한형제들 2023 매출 3조 4155억 원 · 영업이익 6998억 원(전년 대비 흑자전환 · 국내 배달 앱 1위) [출처: 우아한형제들 감사보고서, 2024.04 공시 · 한경/매경 다수 보도]. 배민 광고사업(우리가게·오픈리스트 등)의 매출 기여 명시적 공개는 제한적이나 업계 관측으로 배달 앱 매출의 상당 부분이 광고/수수료 하이브리드 구조 [관찰·추정].

광고 상품 프로파일

1) 우리가게클릭 (CPC 셀프서브 검색광고)

   

↑ 좌: 카테고리 상단 우리가게클릭+오픈리스트 슬롯. 중: 상품 소개 UI. 우: 광고 설정·예산 대시보드. 출처: c1004ok 네이버 블로그

  • 지면 / 트리거: 카테고리(예: 치킨/한식/중식/피자)·검색 결과 리스트 상단 슬롯. 사용자가 카테고리·검색 진입 시 상위 노출. "AD" 라벨 부착 [출처: ceo.baemin.com 배민광고 안내].
  • 크리에이티브 스펙: 매장 프로필(가게명·대표 사진·별점·리뷰수·최소주문금액·배달팁·거리·쿠폰 뱃지). 매장 등록 자산을 그대로 활용해 저공수 O.
  • 클릭 후 인터랙션: 매장 상세(메뉴판/리뷰/사장님 알림)로 이동. 곧바로 주문 카트에 담는 원탭 UX.
  • 넛지 요소: 거리 표시, 최근 리뷰 수, 쿠폰 뱃지("첫 주문 3천원 할인"), "오늘 ○○명이 주문했어요" 소셜프루프 [관찰·추정 · 사장님광장 노하우 콘텐츠에 노출].
  • 타겟팅 / 과금 / 광고주 진입장벽: 위치(동/구 단위)+카테고리 기반 자동 매칭, CPC 실시간 입찰. 최소 예산 낮음. 셀프서브 개설 후 사장님이 직접 광고비 충전·중단 가능 [출처: ceo.baemin.com 광고 안내 페이지].
  • 대표 사례와 성과 수치: 소상공인 셀프서브 채널이므로 대형 브랜드 사례보다 소상공인 후기가 축적. 사장님광장 노하우 콘텐츠에는 "우리가게클릭 예산 하루 5천~2만원으로 신규 리뷰 30%+ 증가" 유형의 후기 다수 [관찰·추정 · 사장님광장 knowhow 카테고리].
  • 소스 신뢰도: 공식 명칭 확인(공식). 성과 수치는 관찰·추정.
  • 카톡 아젠다 매핑: 아젠다 6(오픈채팅 플로팅/띠배너)·아젠다 7(더보기 탭 신규 포맷)·신규 시드(로컬 검색광고).
  • 카톡 적용 시사점: 카톡채널 검색 결과·오픈채팅 방 검색 결과 상단에 CPC 입찰형 로컬 광고를 신설. 셀프서브 UX는 카톡채널 광고센터에 그대로 접목 가능. 위치·카테고리 자동 매칭이 소상공인의 진입장벽을 낮춤 → 카톡 광고 광고주 저변 확대의 핵심 지렛대.

2) 오픈리스트 (지역 상단 3+3 매장 노출)

 

↑ 좌: 오픈리스트 3개 슬롯 노출 방식. 우: 광고 관리 대시보드. 출처: c1004ok 네이버 블로그

  • 지면 / 트리거: 카테고리 리스트 상단의 오픈리스트 3개 슬롯. 사용자가 카테고리 진입 시 랜덤 노출(가입 매장 중 로테이션). 하단 "우리동네 맛집"도 별도 슬롯 [출처: ceo.baemin.com 광고안내 · 사장님광장; 관찰·추정].
  • 크리에이티브 스펙: 매장 프로필. 대표사진·별점·리뷰. 저공수 O.
  • 클릭 후 인터랙션: 매장 상세 → 주문 결제.
  • 넛지 요소: "오픈리스트" 라벨 자체가 자연스러운 노출감(강제 광고감 낮음), 별점·최근 리뷰 노출.
  • 타겟팅 / 과금 / 광고주 진입장벽: 정액제(월 88,000원 부가세 별도) 형태로 알려짐 [관찰·추정, 사장님광장/사장님 커뮤니티]. 카테고리별로 슬롯 개수가 제한돼 있어 지역 경쟁이 격화될수록 대기열/추첨 방식 사용 [관찰·추정].
  • 대표 사례와 성과 수치: 매장주 후기 다수(사장님광장·네이버 카페 "배달의민족 사장님"). 신규 매장의 초기 리뷰 확보용으로 "필수 셋업"으로 인식 [관찰·추정].
  • 소스 신뢰도: 상품명 공식 · 정액제 여부는 관찰·추정.
  • 카톡 아젠다 매핑: 신규 시드. 아젠다 2(커스텀 비즈보드) 소재 크기·형태 참고.
  • 카톡 적용 시사점: 카톡의 카테고리형 지면(선물하기 카테고리 상단, 뷰 탭 카테고리)에 "정액 3개 슬롯 로테이션"을 도입해 소상공인 진입장벽을 낮추는 대안 인벤토리 구성.

3) 울트라콜(구 광고 상품) / 파워콜 (지역 기반 무제한 노출)

 

↑ 울트라콜/파워콜 매장 노출 예시(좌)와 매장 상세 화면(우). 출처: a088 네이버 블로그

  • 지면 / 트리거: 사용자가 카테고리 진입 시 주소 반경 3~5km 내 등록 매장을 노출. 매장이 여러 "깃발"을 뿌리면 여러 반경에 노출 [관찰·추정 · 사장님광장 · 배민사장님 카페 다수 후기].
  • 크리에이티브 스펙: 매장 프로필.
  • 클릭 후 인터랙션: 매장 상세.
  • 넛지 요소: 반경 자유도 → 매장이 원하는 상권 확장.
  • 타겟팅 / 과금 / 광고주 진입장벽: 깃발(광고 지점) 당 월 정액(약 8만원대) 방식으로 통용. 2024 배민 정책 개편으로 일부 지역/카테고리에서 우리가게클릭 CPC로 대체 전환됨 [관찰·추정, 매경/조선비즈 배민 광고 개편 보도].
  • 대표 사례와 성과 수치: 매장주 다수 후기 존재. 다만 2024~2025 개편으로 CPC 상품(우리가게클릭)이 주력으로 이동 [관찰·추정].
  • 소스 신뢰도: 상품 존재 공식(과거) · 세부 요율 관찰·추정.
  • 카톡 아젠다 매핑: 신규 시드(정액 지역 무제한 노출).
  • 카톡 적용 시사점: 정액제 로컬 노출은 소상공인이 예산 예측 가능성을 확보하는 장점 → 카톡의 소식칩/오픈채팅 로컬 지면에 "월 정액 로컬 채널 노출" 상품 검토 시 참고.

4) 우리가게플러스 (프리미엄 노출 + 리포트)

 

↑ 우리가게플러스 패키지 요약(좌)과 사장님 제안서 발췌(우). 출처: bestonebiz 네이버 블로그

  • 지면 / 트리거: 카테고리/검색 리스트 프리미엄 슬롯 + 매장 대시보드 성과 리포트. 우리가게클릭·오픈리스트를 강화한 프리미엄 옵션으로 알려짐 [관찰·추정, ceo.baemin.com 광고 안내].
  • 크리에이티브 스펙: 매장 프로필 + 프리미엄 뱃지("스타 매장" 등) [관찰·추정].
  • 클릭 후 인터랙션: 매장 상세 → 주문.
  • 넛지 요소: 뱃지·상단 고정 노출.
  • 타겟팅 / 과금 / 광고주 진입장벽: 프리미엄 정액/입찰 하이브리드로 알려짐 [관찰·추정].
  • 대표 사례와 성과 수치: 미확인.
  • 소스 신뢰도: 상품 존재 관찰·추정. 정확한 상품 스펙은 사장님광장 페이지에서 재확인 필요.
  • 카톡 아젠다 매핑: 아젠다 1(비즈보드 보장형).
  • 카톡 적용 시사점: 카톡채널의 상단 고정 노출·성과 리포트 결합형 프리미엄 상품 아이데이션.

5) 배민 홈 상단 배너 (프리미엄 CPT/CPM)

 

↑ 배민 홈 최상단 히어로 배너 실 노출 UI. 출처: marketing_secret_ 네이버 블로그

  • 지면 / 트리거: 배민 앱 홈 최상단 히어로 배너. 사용자가 앱을 열면 첫 프레임에 노출되는 위치.
  • 크리에이티브 스펙: 가로형 이미지 + 짧은 카피. 시즌 프로모션·대형 브랜드 위주.
  • 클릭 후 인터랙션: 브랜드 프로모션 페이지·이벤트 페이지·특정 매장 스토어 페이지로 랜딩.
  • 넛지 요소: 카운트다운(라이브 이벤트), 쿠폰 즉시 발급, 브랜드 로고 우측 상단 노출.

사례별 소상세 (Top 5 하이라이트)

케이스 1 · 소상공인 F&B 다수 - 우리가게클릭 · 오픈리스트

케이스 2 · 배민 자체 마케팅(배민문방구·신춘문예·폰트)

케이스 3 · CU × 배민 B마트 (편의점 상품 배달)

케이스 4 · 대형 F&B 브랜드 시즌 프로모션 (롯데리아·코카콜라 등)
