§2 Agenda-by-Agenda

7대 아젠다별 상세 매핑

카톡 내부에서 논의중인 7개 신규 광고 아젠다 각각에 대해, 4개 플랫폼에서 발견된 최상급 벤치마크와 카톡 도입 방향.

01A1

비즈보드 보장형 고도화 — 영상 3초 → 장초

동영상 연장은 소재 관리 구조가 준비되어야 성립. "한 광고세트 안에 여러 비율의 이미지 + 영상"을 동시 등록하는 백엔드가 우선.

  • 토스광고세트-소재 분리 (2026 개편)CPC −42% · CPA −46%
  • 당근동영상 광고 · LG전자 구독구독 전환 3배 개선
  • 당근동영상 광고 · 아케이 (ARKE)ROAS 500%
  • 오늘의집홈피드 네이티브 카드감성 큐레이션
카톡 도입 방향
  • 6~15초 세로형/정방형 영상을 필수 소재로 추가
  • 백엔드에 "광고세트-소재 분리" 구조 도입 (한 세트에 3규격 이미지 + 2규격 영상 등록 → 지면 자동 매칭)
  • 카카오모먼트 자동 배포 로직으로 세컨더리 지면(소식칩·오픈채팅 정보)에 자동 확산
02A2

커스텀 비즈보드 — 동적 스케일·포지션

"커스텀"의 정답은 소재를 여러 개 만드는 것이 아니라 상품 피드만으로 자동 생성되는 오토크리에이티브. 광고주 제작 부담이 대폭 감소하고, 재활용률이 극대화됨.

  • 토스광고세트-소재 분리 (2026)CPC −42% · CPA −46%
  • 당근29CM 카탈로그 리타겟팅ROAS 4,500%+
  • 당근SSG 카탈로그 리타겟팅ROAS 5배+ 개선
  • 당근11번가 카탈로그 리타겟팅MAU 확대 · 구매 KPI +185%
  • 오늘의집스토어 스폰서드 프로덕트피드 기반 오토크리에이티브
카톡 도입 방향
  • 광고주는 가로 3:1(기존) + 정방형 + 세로 4:5 3규격만 등록 → 시스템이 지면에 따라 자동 매칭
  • 톡딜 상품 피드를 활용해 오토크리에이티브 카드 자동 생성
  • "스케일·포지션 변화"는 동일 소재의 지면별 사이즈 매칭 + 카탈로그형 카드 자동 조합의 두 축으로 실현
03A3

보이스톡·페이스톡 종료 광고

액션 완료 순간은 사용자의 방어감이 낮고 성취감이 높아 광고 수용도 상승. 토스가 원칙을 검증했고, 당근 리드폼이 이를 극단화해 상담신청 5배+ 달성.

  • 토스송금 후 화면 배너액션 후 성취감 활용
  • 당근아모레퍼시픽 리드폼상담신청 5배+
  • 당근한화생명 다이렉트 리드폼전환 목표 2배+ 초과
카톡 도입 방향
  • 통화 종료 화면에 디스플레이 배너 + 하프뷰 리드폼 조합
  • 통화 상대와의 관계(친구/그룹) 데이터를 프라이버시 하에 광고 컨텍스트로 활용
  • "5초 상담 신청" 저부담 리드폼 우선 — 금융·보험·자동차·교육 카테고리
04A4 · TOP

선물하기·톡딜 서비스 종료 광고 ★ 최우선

4개 플랫폼 모두에서 최상급 벤치마크가 발견됨. 결제 완료 유저는 지불의사가 검증된 세그먼트라 CPA 효율이 매우 높음. 카톡이 즉시 개발해야 할 아젠다.

  • 배민 ★결제 완료 후 배너카드사 CPA 광고 최적
  • 토스송금 후 배너액션 완료 직후 성취감
  • 당근아모레퍼시픽 리드폼상담신청 5배+
  • 당근29CM 카탈로그 리타겟팅ROAS 4,500%+
  • 오늘의집리타겟팅 DA최근 본 상품 카탈로그
카톡 도입 방향 · 3가지 형태 동시 도입 권장
  • 결제 완료 하프뷰 배너 — 톡딜/선물하기 결제 완료 화면 즉시 노출. 브랜드 배너 or 카드사 CPA
  • 결제 완료 리드폼 — "다음 주문 시 3천원 할인 신청" 등 계정 정보 자동 채움 폼
  • 이탈 시 카탈로그 카드 — 톡딜 상세에서 뒤로가기 시 최근 본 상품 3개 카탈로그 노출
05A5 · TOP

지금탭 숏폼 크리에이터 수익 쉐어 광고

오늘의집 크리에이터 프로그램이 국내 유일 완결형 벤치마크. UGC 콘텐츠 → 상품 태그 → 판매 → 수익 배분 4단계 구조가 상시 운영. 임팩트 스코어 25/25 만점.

  • 오늘의집 ★크리에이터 수익쉐어(집사)임팩트 25 / 25
  • 오늘의집콘텐츠 스폰서(집들이)임팩트 24 / 25
  • 토스앱인토스 스마트 발송pCTR 기반 자동 최적화
카톡 도입 방향
  • 지금탭 숏폼 크리에이터에게 콘텐츠 등록 → 상품 태그 → 판매 발생 → 수익 배분 4단계 인프라 제공
  • pCTR 기반 자동 매칭 → 크리에이터가 광고 셀렉션에 개입할 필요 없음
  • 초기 파일럿 — 오픈채팅 방장·카톡채널 크리에이터 중 트래픽 상위 500명 대상
06A6

오픈채팅 입력필드 위 플로팅·띠배너

채팅 UX는 방어벽이 가장 높은 지면. 배너보다는 접혀있는 링크 카드 형태가 안전. 당근 지역광고를 참고해 채팅방 유형과 어울리는 컨텍스트 광고로.

  • 당근비즈프로필 + 지역광고오픈채팅 방장이 스몰비즈
  • 당근지역 네이티브 카피"○○동 이웃분들께"
  • 배민우리가게클릭 (CPC)30만+ 소상공인 셀프서브
카톡 도입 방향 · 신중 접근
  • 채팅 입력 필드 위에는 배너 대신 접혀있는 어필리에이트 카드 (사용자 확장 시에만 펼침)
  • 채팅방 주제·참여자 지역·시간대 시그널을 결합한 컨텍스트 광고
  • 초기 파일럿은 오픈채팅 특정 카테고리(취미·지역·중고거래)만 제한적 도입
07A7

더보기 탭 신규 광고 포맷

더보기 탭은 능동 진입 지면. 참여형·리워드형·리드폼에 적합. 토스 혜택 탭이 리워드 5종을 집중 배치해 검증했고, 당근 리드폼은 능동 진입 유저에게 강력.

  • 토스두근두근 1등 찍기클릭률 5% · 190만+ 클릭
  • 당근신기한나라 리드폼DB 수집 KPI 150%
  • 배민배민문방구·콘텐츠 광고브랜드 IP 콜라보
  • 오늘의집브랜드관 (스토어)상시 운영 지면
카톡 도입 방향 · 기존 2:1 배너 대체
  • 카탈로그 투표형 광고 — 6~10개 SKU 중 사용자 투표. 카톡 초코·이모티콘 조각 리워드 결합
  • 리드폼 카드 — 상담 신청·자료 요청 폼. 카톡 계정정보 자동 채움
  • 브랜드 스토어 진입 카드 — 톡채널을 브랜드 스토어형으로 재구성
§3 New Ideas

전환률 높은 디스플레이 광고 · 신규 아이디어 8

4개 플랫폼 사례에서 도출한 전환률 결정 4축 — 컨텍스트·개인화·인터랙션·소재 자동화 — 을 조합해 만든 여덟 개의 신규 광고 상품 아이디어. 각 아이디어는 참고 사례·적용 지면·전환률 근거·개발 스펙까지 정의됨. 필터로 좁혀보세요.

01★ TOP 1

하프뷰 리드폼

Half-View Lead Form

광고 클릭 시 화면 하단에서 하프뷰 시트가 올라오며 폼 오픈. 카톡 계정정보(이름·연락처·주소·이메일)가 자동으로 채워지고, 사용자는 확인·제출만.

카탈로그 오토크리에이티브

광고주는 상품 피드 하나만 등록. 시스템이 사용자 조회·장바구니 이력 기반으로 최근 본 상품 3~6개를 자동 카드화. 지면 규격에 맞춰 사이즈·레이아웃 자동 매칭.

REF 당근 29CM ROAS 4,500%+ · SSG 5배+ · 11번가 KPI +185% · 토스 CPC −42% FIT 아젠다 2·4 · 커스텀 비즈보드/톡딜 종료/소식칩
Dev 중 임팩트 최상 신뢰도 최상
03★ TOP 3

액션 완료 컨텍스트 배너

톡딜/선물하기 결제 완료, 통화 종료, 이모티콘 다운로드 등 액션 완료 화면에 컨텍스트 매칭 배너 노출. 카피는 방금 완료한 액션과 연관성 필수.

REF 배민 결제 완료 후 배너 · 토스 송금 후 배너 FIT 아젠다 3·4 · 톡딜/선물하기 결제 완료/통화 종료

개인화 카피 자동 삽입

05

지면 간 시너지 · 통합 광고 여정

3개 지면이 독립적으로 존재하기보다 하나의 사용자 여정으로 연결되면 CVR이 배가됩니다. 이는 토스·당근·배민·오늘의집 어느 플랫폼도 갖지 못한 카톡 고유의 강점.

  1. 소식칩에서 카탈로그 캐러셀로 인지 → 상품 페이지 방문
  2. 숏폼 크리에이터 콘텐츠 스폰서로 신뢰 형성 → 리타겟팅
  3. 채팅탭 대화 완료 후 배너로 재유입 → 결제 완료

이 3단계 퍼널을 하나의 광고주 캠페인으로 판매하면 카톡만의 "메신저 안 통합 광고 여정" 상품이 됩니다.

Baemin · 2026.07 광고소개서 & 제작 가이드

배민이 방금 공개한 신규 광고 상품의 단가·성과Newest Benchmark

2026-07 광고소개서(우아한형제들 광고상품기획팀)와 배민 공식 광고 제작 가이드(bm-with-design.woowahan.com) 11개를 통합. 공시 단가 vs 협상 단가가 함께 표기되고, CTR 벤치마크와 광고주 성과 사례가 명시된 공식 자료. 카톡 광고 상품 판매 정책·목표 CTR 설정의 실질적 참고선.

리뷰완료 배너
CTR 20%
배민 자체 예상 CTR. 리뷰 작성 완료 직후 노출되는 지면이라 방어감 최소. 아젠다 4(선물하기·톡딜 종료 광고) 도입 시 목표 CTR 벤치마크.
중문배너 (바텀시트→플로팅)
CTR 7~9%
1일 50만 노출. 사용자가 광고를 완전히 닫지 않고 최소화만 하는 인터랙션. 카톡 톡딜 프로모션 배너에 즉시 이식 가능.
검색 서제스트
CTR 3.87%
1개월 독점 패키지. 19개 카테고리 운영. 카톡 검색 광고 신설의 단가·성과 벤치마크.

공식 성공 사례 5개 · KPI 명확

배민이 광고소개서에서 직접 공표한 사례. 벤치마크 대비 편차가 크게 명시됨.

▸ 카톡 개발 시사점 5가지
  1. 리뷰완료 배너 CTR 20% 예상 — 아젠다 4(선물하기·톡딜 종료 광고) 도입 시 목표 CTR로 활용. 배민이 이미 상업적 가치 검증.
  2. 바텀시트→플로팅 최소화 인터랙션 — 사용자가 광고를 닫지 않고 축소만 하는 UX. 카톡 프로모션 배너에 이식.
  3. 공시 단가 vs 협상 단가 표기 방식 — 대행사 판매 표준. 카톡 카카오모먼트 판매 페이지 개편 시 참고.
  4. 타겟팅 할증 10% (최대 50% 누적) — 광고주 옵션 판매 표준 스킴. 결제 카드명·메뉴명까지 세분화된 결제 데이터 리타겟팅.
  5. LTE 5초 자동재생 후 정지 — 배달현황 동영상 정책. 카톡 숏폼 광고에 이식 시 사용자 저항 크게 감소.

§6 Roadmap

§7 Open Questions

팀 논의를 위한 열린 질문

리서치가 답하지 못하고 팀·조직 논의로 결정해야 하는 지점들. 아이디어 도입 결정 전 반드시 답해야 할 질문.

A. 개인정보·프라이버시

  • 카톡 계정정보 자동 채움(리드폼)은 개인정보처리방침 개정 필요? 옵트인 UX 어떻게 설계?
  • 통화 종료 화면에서 통화 상대와의 관계 데이터 활용은 프라이버시 관점에서 어디까지 가능?

B. UX 방어선

  • 오픈채팅에 광고 도입 시 사용자 반발 리스크는? 파일럿 카테고리를 어떻게 좁힐지?
  • "과도한 게이미피케이션 배제" 원칙 안에서 리워드 투표형 카탈로그를 어떻게 규제할지?

C. 광고 매출 전략

  • 소상공인 셀프서브 인벤토리(롱테일) vs 대형 브랜드 프리미엄(빅헤드) 어떤 축을 먼저?
  • 크리에이터 커미션율(권장 8~15%) 검토는 어느 조직에서?

D. 성과 측정

  • ROAS 지표는 이커머스만 측정 가능. 리드폼·브랜드 광고는 어떤 KPI로 광고주에게 제시할지?
  • 아젠다별 초기 A/B 테스트 설계 (전환률 벤치마크 대비)
